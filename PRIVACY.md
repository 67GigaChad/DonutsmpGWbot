# Privacy

This bot stores only what it needs to run giveaways:

- Your Discord user ID and the Minecraft/DonutSMP username you enter
- Per-server settings (channel and role IDs) and giveaway records (prize, host, entries, winners)

It does not read message content and does not collect anything else. Finished giveaways are deleted after 30 days.
Run `/forgetme` to delete your saved username and leave running giveaways. Removing the bot from a server deletes that server's data.

This project is not affiliated with DonutSMP or Discord.
